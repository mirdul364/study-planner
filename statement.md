# Problem Statement

## Problem
College students often struggle to organise their study hours across subjects, and to practise the core problem-solving algorithms taught in their first programming course. Notes and plans end up scattered, and there is no single place to track progress.

## Scope
A console-based Python application that:
- manages a study plan (add, view, complete, remove, search, sort),
- generates a progress report,
- includes an Algorithm Lab where fundamental algorithms can be run on user input.

Out of scope: user accounts, databases, saving data to files, and graphical interfaces. The plan lives in memory while the program runs.

## Target Users
First-year college students learning problem solving and Python programming.

## High-Level Features
1. **Study Plan Management** - add, view, complete, remove, search and sort subjects.
2. **Report** - total items, completed, pending, total and remaining hours, completion percentage.
3. **Algorithm Lab** - factorial, Fibonacci, reverse text, base conversion, GCD, primes, prime factors, smallest divisor, square root.
